# Genrick Schwartz — Profile & Portfolio

A readable, professional portfolio designed for people who prefer straightforward navigation. The page includes a personal profile, skills, project summaries, and LinkedIn / GitHub profile links.

## Preview

Open `index.html` in a browser. The page works without installing anything. All styling is contained in the HTML file; there are no external fonts, libraries, or trackers. The `assets` folder holds the local sample videos and their preview images.

## Publish the portfolio

Suggested repository name: `genrockstar.github.io`.

1. Create that public repository under the `genrockstar` account.
2. Upload `index.html`, the `assets` folder, and `.nojekyll` to its root. If the upload screen does not show `.nojekyll`, the HTML page can still be published without it.
3. Open Settings → Pages. Under Build and deployment, choose Deploy from a branch, select `main` and `/ (root)`, then Save.
4. Verify the published site before sharing it.

Expected address after publication: https://genrockstar.github.io/
This address is an intended destination, not a confirmed live deployment.

Official setup guide: https://docs.github.com/en/pages/quickstart
